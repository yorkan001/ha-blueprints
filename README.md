# Home Assistant blueprinti

Home Assistant blueprints by netvis.hr

Javna zbirka Home Assistant blueprinta tvrtke netvis.hr (Haru). Blueprinti su namijenjeni dijeljenju s klijentima: svaki se u vlastiti Home Assistant uvodi jednim klikom na gumb za uvoz.

## Blueprinti

| Blueprint | Uvoz |
| --- | --- |
| [Siguran impuls za vrata](blueprints/script/haru/README.md) | [![Open your Home Assistant instance and show the blueprint import dialog with a specific blueprint pre-filled.](https://my.home-assistant.io/badges/blueprint_import.svg)](https://my.home-assistant.io/redirect/blueprint_import/?blueprint_url=https%3A%2F%2Fgithub.com%2Fyorkan001%2Fha-blueprints%2Fblob%2Fmain%2Fblueprints%2Fscript%2Fharu%2Fsiguran_impuls_vrata.yaml) |

## Ručna instalacija

Ako gumb ne otvori vašu instancu: **Postavke → Automatizacije i scene → Blueprinti → Uvezi blueprint** (*Import Blueprint*), zalijepite GitHub URL datoteke, zatim *Pregled* i *Uvezi*.

Za *Siguran impuls za vrata*:

`https://github.com/yorkan001/ha-blueprints/blob/main/blueprints/script/haru/siguran_impuls_vrata.yaml`
